# Mehran Rahnamania — Academic Website

A responsive academic portfolio published with GitHub Pages.

## Deploy

In the repository, open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/(root)`, and save. The site will be available at https://mehranrahnamania.github.io/ after deployment.

## Update

Edit `index.html` to update the biography, research interests, publications, projects, experience, or contact links. All publication statuses are stated as described in the supplied CV. Google Scholar is linked directly; citation metrics are not hard-coded.
